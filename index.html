Windows Calendar Bridge

A personal tool that keeps the Windows 10 taskbar calendar in sync with its owner's Google Calendar. It is used only by its owner and is not offered to anyone else.

Privacy policy

The app accesses only the Google account of the person who signed in to it, and only these permissions:

  • View and edit events on that person's calendars, to copy events between Google Calendar and the Windows calendar on the same PC.
  • View the calendar list, to know which calendars to sync.

Calendar data is stored only on the owner's own Windows PC, in the Windows calendar and in a sync-state file encrypted with the owner's Windows account. Nothing is sent to any server other than Google's own Calendar API. No data is shared, sold, or used for any other purpose.

Access can be revoked at any time at myaccount.google.com/permissions.
